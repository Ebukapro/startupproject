## What this generation knows that run 1 didn't

Run 1 generated names that sound good, then discovered 87% were registered. This
generation is built on the evidence from that gate:

1. **Aesthetic plausibility is the enemy.** Names that read like a real place or
   object (`keelstone`, `larkstone`, `beamhouse`, `cairnpost`) were swept up by
   domain investors years ago. Arbitrary pairings survive. So: pair words that do
   **not** naturally collocate.
2. **Banned suffixes:** `-stone`, `-house` — all four died in run 1.
3. **Banned shapes:** 6–7 letter coinages. `torven` and `rondeva` both died. The
   brief warned about 4–5 letters; reality is worse. Coinages here are 8–10.
4. **Second elements are market vocabulary** — lot, basis, parity, mark, path, way,
   book — which are ordinary words that rarely pair with the first element.
5. **Aimed at Agent 1's open territories:** light/clarity (used once globally by
   Lightyear, never in Nigeria), everyday wayfinding, and agency/ownership verbs.
6. **`-ledger` and `-tally` used sparingly.** Ledger is a dominant litigious crypto
   brand; Tally is a live USPTO fintech mark.

All original hard constraints applied: no return-implying words, no
regulated-status words, no `-vest`/`invest`, no geography, pronounceable on first
sight, no incumbent homophones, no `bourse` (Agent 7's ruling).
