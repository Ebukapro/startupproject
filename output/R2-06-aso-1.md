# Agent 6 — Search & App Store Discoverability (Shard 1)
Nigerian retail stock-trading app, bootstrapped, zero paid acquisition. Assessed 17 candidates for free/organic findability: Google SERP ownability, Wikipedia/knowledge-panel entities, App Store collision (iTunes Search API, country=NG), and autocomplete-prefix contamination.

## Method notes
- SERP: WebSearch on bare name, `{name} app`, and `{name} nigeria`/`invest` where the base word suggested a real risk.
- Store collision: `itunes.apple.com/search?term=<exact name>&country=NG` — all 17 exact compounds returned **zero results** (no existing app owns any of these exact strings).
- Autocomplete: approximated by querying the iTunes API with 4-letter prefixes (per the flagged list: Comp-, Anch-, Rout-, Cand-, Torc-, Dawn-, Fair-, Beac-, Lant-) plus Trai-, Plai-, Leve-, Teno-, and full base words (Compass, Anchor, Route, Trail, Level, Plain, Beacon, Lantern, Candle, Torch, Fair, Dawn) against the NG storefront. This is a proxy for App Store search-suggest, not the real algorithm — flagged as approximate.
- Volume: no working trends tool: judged qualitatively only (SERP thinness/richness), never numeric. All volume figures are UNVERIFIED by design.
