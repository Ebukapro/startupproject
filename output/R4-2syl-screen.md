# R4 — Two-Syllable Brand Name Screen (18 candidates)
Client: Tecdrich Technologies Ltd. Register target: Kuda / Monzo / Chime / Claude (warm, plain, trustworthy).
Method: linguistic analysis (Yoruba/Igbo/Hausa/Pidgin/Swahili/French/Portuguese/Arabic/Spanish/Italian) by model knowledge; iTunes Search API (NG storefront) for app-store collisions; WebSearch for trademark/brand-association risk on flagged names. Google/CAC/social searches were blocked — marked UNVERIFIED where relevant.

**Result: 0 STRONG, 8 USABLE, 10 REJECT.** These names were bred for domain availability, not for sound — it shows. Ten of eighteen collapse onto an existing common name, brand, or word the instant they're spoken aloud, which is the one failure mode a word-of-mouth, bootstrapped consumer app cannot survive.

---

## Cross-cutting pattern found
Two suffix families in this batch are structurally dangerous, independent of the individual name:
- **"-wick" names rhyming with Warwick/Berwick** (Sarwick, Verwick, and to a lesser extent Brawick): all get pulled toward a real, well-known word/brand by sheer rhyme pressure.
- **"-wen" names echoing Tolkien's "Arwen"** (Dorwen, Sarwen, Tarwen, Zarwen): all read slightly fantasy/elvish rather than fintech-warm; Dorwen is worst because it's *also* a real English name (Dorwin/Doreen).
- For **Verwick** specifically: several Nigerian speakers' L1 phonology does not sharply distinguish /v/ and /w/, so "Verwick" risks being produced and heard as "Warwick" by exactly the target audience — this is a Nigeria-specific aggravation of an already-bad rhyme collision.

## Ranked top 8 (all usable candidates — fewer than 10 cleared the bar)

1. **Tarvick** — cleanest across every check: no meaning hits, no collision, sounds like a real surname a first-time investor would trust with money.
2. **Fenvon** — distinctive and collision-free; only ding is a slightly formal "von" register that's easy to warm up with tone-of-voice/branding.
3. **Tervick** — nearly as strong as Tarvick, just marginally less distinct as a standalone word.
4. **Fenvell** — solid and safe; "Fennell" echo is a real word but not a competing brand or a fintech-space collision.
5. **Brawick** — pleasant and sayable; main risk is drifting to "Berwick" in transcription, which is manageable with clear spelling in-app.
6. **Tarwen** — best of the "-wen" family; light Tolkien/"Arwen" echo but doesn't collide with a real name or brand.
7. **Sarwen** — same Arwen echo as Tarwen, marginally less crisp on the front syllable.
8. **Zervick** — usable but weakest: the Z-initial pushes it toward sci-fi/robot territory, working against the "warm, approachable" brief.

## Rejected (10) — one-line reason each
- **Sarwick** — near-homophone of "Warwick" (major existing brand).
- **Verwick** — same Warwick collision, worsened by /v/-/w/ overlap in Nigerian speech.
- **Dorwen** — collapses to "Doreen"/"Dorwin," real common names.
- **Zarwen** — doubled fantasy signal (Z- + "-wen"), reads as an RPG character.
- **Danvell** — collapses to "Danielle" on hearing.
- **Kelvell** — collapses to "Kelvin," a very common Nigerian name.
- **Cadvar** — embeds the English word "cad" (a dishonest man) — bad money-app association.
- **Fernvo** — echoes "Venmo," risky given planned US expansion.
- **Gaflin** — reads as a pharmaceutical name (confirmed via drug-name search collisions).
- **Bravton** — collapses to "Braxton" (active trademark space) / "Brighton."
