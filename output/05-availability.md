# Agent 5 — Trademarks, Handles & Association Risk
Shortlist-36 assessment for Tecdrich Technologies' NGX/US retail stock-trading app.

**Scope note:** this covers trademark conflicts, company-name conflicts, social-handle contention, and association/reputation risk only. App-store naming and search-ranking collisions are Agent 6's remit and are not duplicated here.

**Method / verifiability:** Nigeria trademark search (iponigeria.gov.ng), CAC company search (search.cac.gov.ng), and all four social platforms (x.com/twitter.com, instagram.com, linkedin.com, tiktok.com) returned CONNECT-denied or 403 from this environment and could not be queried directly — see the dedicated UNVERIFIED section below. WIPO Global Brand Database and USPTO TESS were reachable in principle, but in practice the fastest reliable route to indexed USPTO/WIPO filing data was via WebSearch against Justia Trademarks and Trademarkia (both of which mirror USPTO records), plus targeted WebSearch queries for companies, scams, and Nigeria-specific hits. No claim below states a handle or filing status that WebSearch did not actually surface; where WebSearch returned nothing, that is recorded as "no evidence found," never as "confirmed free."

## UNVERIFIED — requires human check

**Every candidate below is unverified for the specific source named — this is not a statement that the name is available, only that this review could not check it.**

### Nigeria trademarks (all 36 names)
`iponigeria.gov.ng` returned CONNECT-denied from this environment for the entire session. **No Nigerian trademark register check was possible for any of the 36 candidates.** A Nigerian trademark attorney search (Trademarks, Patents & Designs Registry, Abuja) is required before any final selection, particularly for the 24 names marked CLEAR/CONTESTED above on the basis of US/WIPO-adjacent evidence only.

### Nigerian company-name conflicts (all 36 names)
`search.cac.gov.ng` returned 403 from this environment for the entire session. Company-conflict findings above for Bollard, Corbel, Camber, Windlass, Quantal, Lintel were sourced from **general WebSearch results that happened to surface CAC-adjacent or third-party business-directory listings** (e.g., b2bhint.com mirrors of CAC filings), not a direct CAC search. This is suggestive, not authoritative. **A direct CAC company search is required for all 36 names**, especially the 24 not flagged above, before assuming no Nigerian company-name conflict exists.

### EUIPO (all 36 names)
`euipo.europa.eu` was listed as blocked and was not queried at all. No EU trademark register check was performed for any candidate. This matters most for the names already showing EU-adjacent hits via WebSearch (Indexel — France; Lumera — Carl Zeiss/Syngenta Europe) and should be checked directly.

### Social handles — exact-string availability (all 36 names)
`x.com`, `twitter.com`, `instagram.com`, `linkedin.com`, `tiktok.com` all returned CONNECT-denied. Every "handle" finding in the table above is inferred from **WebSearch's indexed snapshots of those platforms**, which:
- can surface an existing account (treated as real evidence above, e.g., @BollardGroup, @norvelltanning, @longtidefinancialpartners, @lumeragroup), but
- **cannot confirm that an exact candidate string (e.g., a plain `@tenura`, `@quantal`, `@corbel`, or `@bollard` with no suffix) is actually free**, even where no conflicting account was found in search results.

For every name marked CLEAR above (Rondeva, Librova, Stavion, Northbell, Larkstone, Tallyhouse, Mainmast, Truetenor, Lotline, Tickline, Midprice, Foredeck), the correct reading is "no conflicting use was found via WebSearch," **not** "the exact handle is confirmed available." A human (or a tool with live platform access) must check the literal handle strings on X, Instagram, LinkedIn and TikTok — including common suffixes (`app`, `hq`, `ng`, `official`) — before any name is locked in, and must specifically re-verify whether one consistent handle across all four platforms is achievable for the finalist(s).

### WIPO Global Brand Database — direct queries
`branddb.wipo.int` was reachable per the brief, but its search UI is a JavaScript application not amenable to a simple fetch; WIPO-registered marks were instead inferred from WebSearch results referencing USPTO/Justia/Trademarkia filings (which include Madrid Protocol / international registrations where relevant) rather than a direct branddb.wipo.int query. For any finalist, a direct WIPO Global Brand Database search (by a human or a browser-capable tool) is recommended to catch non-US-origin international registrations this method could have missed.
